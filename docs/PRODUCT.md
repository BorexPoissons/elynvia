# ELYNVIA Life — Product v0.1

## Product promise

**Your Life. Your Agent.**

Tell ELYNVIA what you want to accomplish. ELYNVIA understands the intention, organizes what matters and helps move toward a useful result.

## Primary V1 user journey

1. User signs in.
2. User opens ELYNVIA Life.
3. User writes a natural request.
4. ELYNVIA extracts a structured Intent.
5. ELYNVIA communicates what it understood in a human way.
6. If essential information is missing, ELYNVIA asks a minimal follow-up question.
7. A complex goal can become a Project.
8. Conversation and project state remain available later.

## UX principles

- Start from a large natural-language input, not a complex dashboard.
- Do not force users to choose a category before speaking.
- Avoid long forms when conversation can collect information naturally.
- Make AI assumptions visible when they matter.
- Let users correct structured information.
- Separate suggestions from actions requiring permission.
- Preserve continuity without creating mysterious or uncontrollable memory.

## Intent vs Project

An Intent represents what the user wants.

A Project represents ongoing work required to accomplish a sufficiently complex Intent. A Project may contain multiple related Intents over time.

## V1 success criteria

V1 is successful when a user can provide varied real-world requests and ELYNVIA consistently:

- identifies the main goal;
- extracts useful constraints;
- distinguishes known from missing information;
- avoids inventing critical facts;
- asks useful follow-ups;
- stores the state safely;
- lets the user continue later.

## Not an engagement feed

ELYNVIA Life should not optimize for infinite scrolling or time spent. The principal product metric should trend toward successful outcomes, useful progress and user trust.
